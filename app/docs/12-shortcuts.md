# キーボードショートカット一覧

## 基本操作

### ファイル操作

| 操作 | Windows/Linux | Mac | 説明 |
|------|--------------|-----|------|
| 新規作成 | `Ctrl + N` | `Cmd + N` | 新しいノードを作成 |
| 開く | `Ctrl + O` | `Cmd + O` | ノードを開く |
| 保存 | `Ctrl + S` | `Cmd + S` | 現在のノードを保存 |
| すべて保存 | `Ctrl + Shift + S` | `Cmd + Shift + S` | すべての変更を保存 |
| 閉じる | `Ctrl + W` | `Cmd + W` | 現在のタブを閉じる |
| すべて閉じる | `Ctrl + Shift + W` | `Cmd + Shift + W` | すべてのタブを閉じる |
| 印刷 | `Ctrl + P` | `Cmd + P` | 印刷ダイアログを開く |

### 編集操作

| 操作 | Windows/Linux | Mac | 説明 |
|------|--------------|-----|------|
| 元に戻す | `Ctrl + Z` | `Cmd + Z` | 直前の操作を取り消す |
| やり直し | `Ctrl + Y` / `Ctrl + Shift + Z` | `Cmd + Shift + Z` | 取り消した操作をやり直す |
| カット | `Ctrl + X` | `Cmd + X` | 選択項目を切り取る |
| コピー | `Ctrl + C` | `Cmd + C` | 選択項目をコピー |
| ペースト | `Ctrl + V` | `Cmd + V` | クリップボードから貼り付け |
| すべて選択 | `Ctrl + A` | `Cmd + A` | すべての項目を選択 |
| 削除 | `Delete` | `Delete` | 選択項目を削除 |
| 名前変更 | `F2` | `F2` / `Enter` | ノードの名前を変更 |

## カスタムショートカット

### 設定方法

1. 設定画面を開く（`Ctrl + ,`）
2. 「キーボードショートカット」セクションへ
3. 変更したいコマンドを検索
4. 新しいキーの組み合わせを入力
5. 保存

### おすすめカスタマイズ

```
よく使う機能に独自のショートカットを割り当て：

例：
Ctrl + Shift + P: コマンドパレット
Ctrl + Shift + D: 今日の日付を挿入
Ctrl + Alt + T: テンプレート選択
Ctrl + Alt + E: エクスポート
```

## トラブルシューティング

### ショートカットが効かない場合

1. **入力フィールドにフォーカス**: `Esc`キーで解除
2. **他のアプリとの競合**: システム設定を確認
3. **ブラウザの制限**: 一部のキーはブラウザが予約
4. **カスタム設定の確認**: 設定画面で確認

### リセット方法

設定 → キーボードショートカット → 「デフォルトに戻す」
