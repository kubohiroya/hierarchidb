# 検索と絞り込み - 効率的なデータ検索

## 検索機能の概要

HierarchiDBの検索機能を使用すると、大量のデータから必要な情報を素早く見つけることができます。基本的なテキスト検索から、高度な条件検索まで様々な検索方法を提供しています。

### 検索の種類

```
🔍 検索機能一覧:
• クイック検索 - 簡易テキスト検索
• 詳細検索 - 複数条件の組み合わせ
• 全文検索 - コンテンツ内も検索
• 正規表現検索 - パターンマッチング
• スマート検索 - AI支援検索
```

## クイック検索

### 基本的な使い方

ツールバーの検索ボックスで即座に検索：

```
🔍 [検索キーワード    ] [Enter]

リアルタイム候補表示:
├── 📄 企画書_2024
├── 📁 企画部門
└── 📝 新企画案
```

### 検索のコツ

#### キーワードの入力
- **部分一致**: `企画` → 「企画書」「新企画」など
- **完全一致**: `"企画書"` → 「企画書」のみ
- **OR検索**: `企画 OR 提案` → どちらかを含む
- **AND検索**: `企画 AND 2024` → 両方を含む
- **NOT検索**: `企画 NOT 却下` → 「却下」を含まない

### ショートカット

```
検索ショートカット:
Ctrl + F: 検索開始
F3: 次の結果へ
Shift + F3: 前の結果へ
Esc: 検索終了
```

## 詳細検索

### 詳細検索パネル

複数条件を組み合わせた検索：

```
詳細検索条件:
━━━━━━━━━━━━━━━━━━━━━━━━
キーワード: [        ]
ノードタイプ: [すべて ▼]
作成日: [2024/01/01] ～ [2024/12/31]
更新日: [最近7日間 ▼]
作成者: [すべて ▼]
タグ: [重要 ▼] [進行中 ▼]
━━━━━━━━━━━━━━━━━━━━━━━━
[検索] [リセット]
```

### 条件の組み合わせ

#### 論理演算子
```
AND条件（すべて満たす）:
タイプ = "ドキュメント"
AND 更新日 >= "2024-03-01"
AND タグ = "重要"

OR条件（いずれか満たす）:
作成者 = "山田"
OR 作成者 = "佐藤"

複合条件:
(タイプ = "タスク" AND ステータス = "未完了")
OR (タグ = "緊急")
```

### 検索テンプレート

よく使う検索条件を保存：

```
保存済み検索:
📌 今週の更新 - 更新日 >= 月曜日
📌 自分のタスク - 担当者 = 自分 AND 未完了
📌 期限切れ - 期限 < 今日 AND 未完了
📌 レビュー待ち - ステータス = "レビュー"

[新規テンプレート作成]
```

## 正規表現検索

### パターンマッチング

高度なパターン検索：

```
正規表現の例:
```

## 検索の最適化

### パフォーマンス向上

```
検索速度改善のヒント:
• インデックスを最新に保つ
• 検索範囲を限定する
• 不要なプロパティを除外
• キャッシュを活用
```

### 検索戦略

#### 段階的な絞り込み
1. 広い条件で検索
2. 結果を確認
3. 条件を追加して絞り込み
4. 必要に応じて条件を調整

#### 効率的なキーワード選択
```
良い例:
✅ 特徴的な単語を使用
✅ 複数のキーワードを組み合わせ
✅ 日付や数値で範囲指定

避けるべき例:
❌ 一般的すぎる単語
❌ 一文字での検索
❌ 冗長な条件
```
