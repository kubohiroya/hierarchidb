# トラブルシューティング - よくある問題と解決方法

## 起動・ログインの問題

### アプリケーションが起動しない

#### 症状
ブラウザでアプリケーションにアクセスしても画面が表示されない

#### 解決方法
```
チェックリスト:
☑ インターネット接続を確認
☑ ブラウザのキャッシュをクリア
  Chrome: Ctrl + Shift + Delete
☑ 別のブラウザで試す
☑ ブラウザを最新版に更新
☑ 拡張機能を無効化して試す
```

### ログインできない

#### 症状
認証画面でエラーが表示される、またはループする

#### 解決方法
```
対処法:
1. Cookieとキャッシュをクリア
2. プライベートモードで試す
3. ポップアップブロッカーを無効化
4. 正しいアカウントを使用しているか確認
5. パスワードをリセット
```

## データの問題

### データが表示されない

#### 症状
ツリーやノードが表示されない、空白の画面

#### 原因と対策
```
確認事項:
━━━━━━━━━━━━━━━━━━━━━━━━
❓ ローカルストレージの容量不足
→ 不要なデータを削除

❓ IndexedDBのエラー
→ ブラウザの開発者ツールでエラー確認
→ IndexedDBをクリア（設定 → データ管理）

❓ 同期エラー
→ オフライン/オンラインを切り替え
→ 手動で同期を実行
━━━━━━━━━━━━━━━━━━━━━━━━
```

### 変更が保存されない

#### 症状
編集した内容が保存されない、消えてしまう

#### 解決方法
```javascript
// ブラウザコンソールで確認
navigator.storage.estimate().then(estimate => {
  console.log(`使用量: ${estimate.usage}`);
  console.log(`上限: ${estimate.quota}`);
});
```

```
対処法:
1. 自動保存が有効か確認（設定 → 編集）
2. プライベートモードではないか確認
3. ストレージ容量を確認
4. 手動保存を試す（Ctrl + S）
```

## パフォーマンスの問題

### 動作が遅い・重い

#### 症状
操作に対する反応が遅い、フリーズする

#### 最適化方法
```
パフォーマンス改善:
━━━━━━━━━━━━━━━━━━━━━━━━
1. 不要なタブを閉じる
2. 大きなツリーを折りたたむ
3. フィルターで表示項目を減らす
4. ブラウザのハードウェアアクセラレーションを有効化
5. メモリ使用量を確認：
   Chrome: Shift + Esc でタスクマネージャー
━━━━━━━━━━━━━━━━━━━━━━━━
```

### メモリ不足エラー

#### 症状
「メモリ不足」のエラーメッセージ

#### 解決方法
```
メモリ管理:
• 他のアプリケーションを終了
• ブラウザの他のタブを閉じる
• 大きなファイルを分割
• 64bit版ブラウザを使用
• PCのメモリを増設
```

## 表示の問題

### レイアウトが崩れる

#### 症状
UI要素が重なる、正しく配置されない

#### 解決方法
```
表示リセット:
1. ズームを100%にリセット（Ctrl + 0）
2. ウィンドウサイズを調整
3. 表示設定をデフォルトに戻す
4. ブラウザの拡大率を確認
5. CSSキャッシュをクリア
```

### アイコンや画像が表示されない

#### 症状
アイコンが□や×で表示される

#### 対処法
```
確認項目:
☑ インターネット接続
☑ 広告ブロッカーを無効化
☑ セキュリティソフトの設定
☑ プロキシ設定
☑ フォントの読み込み設定
```

## 検索の問題

### 検索結果が表示されない

#### 症状
検索しても結果が0件、エラーが出る

#### 解決方法
```
検索インデックスの再構築:
1. 設定 → 検索 → インデックス管理
2. 「インデックスをクリア」
3. 「インデックスを再構築」
4. 完了まで待つ（プログレスバー表示）
```

### 検索が遅い

#### 最適化
```
検索速度改善:
• 検索範囲を限定
• 正規表現を簡潔に
• インデックスを最新に保つ
• 不要なプロパティを検索対象から除外
```

## インポート/エクスポートの問題

### インポートが失敗する

#### エラー別対処法

```
エラー: "Invalid format"
→ ファイル形式を確認（JSON, CSV, Excel）
→ 拡張子と実際の形式が一致しているか

エラー: "File too large"
→ ファイルを分割してインポート
→ 圧縮してサイズを削減

エラー: "Encoding error"
→ 文字コードをUTF-8に変換
→ BOMなしで保存

エラー: "Parse error"
→ JSONの構文エラーを修正
→ CSVの区切り文字を確認
```

### エクスポートが失敗する

#### 症状と対策
```
問題: ダウンロードが開始されない
→ ポップアップブロッカーを確認
→ ダウンロードフォルダの権限確認

問題: ファイルが破損している
→ 別の形式でエクスポート
→ 小さい範囲でテスト

問題: 文字化けする
→ 文字コードをUTF-8に設定
→ Excelの場合はBOM付きUTF-8
```

## プラグインの問題

### プラグインが動作しない

#### 診断手順
```
プラグイン診断:
1. プラグインが有効か確認
2. 必要な権限が付与されているか
3. 依存関係のチェック
4. プラグインを再インストール
5. 別のプラグインとの競合を確認
```

### プラグインエラー

#### エラーログの確認
```javascript
// ブラウザコンソールで実行
console.log('プラグインステータス:');
HierarchiDB.plugins.getStatus();
```

## ネットワークの問題

### オフラインで使用できない

#### 設定確認
```
オフライン設定:
1. Service Workerが有効か確認
   Chrome: chrome://serviceworker-internals/
2. キャッシュ設定を確認
3. PWAとしてインストール
```

### 同期エラー

#### 症状
データが他のデバイスと同期されない

#### 解決方法
```
同期トラブルシューティング:
1. ネットワーク接続を確認
2. 同期設定を確認（設定 → 同期）
3. 手動同期を実行
4. 競合の解決
5. 同期をリセット
```

## ブラウザ別の問題

### Chrome/Edge

```
よくある問題:
• 拡張機能の競合 → シークレットモードで確認
• ハードウェアアクセラレーション → 設定で切り替え
• サイトの設定 → chrome://settings/content
```

### Firefox

```
よくある問題:
• トラッキング防止 → 例外に追加
• プライバシー設定 → Cookieを許可
• about:config → 詳細設定を確認
```

### Safari

```
よくある問題:
• ITP（Intelligent Tracking Prevention） → 無効化
• WebGL → 開発メニューで有効化
• ローカルストレージ → 設定で確認
```

## エラーメッセージ一覧

### よくあるエラーと対処法

| エラーメッセージ | 原因 | 対処法 |
|-----------------|------|--------|
| `NetworkError` | ネットワーク接続なし | 接続を確認 |
| `QuotaExceededError` | ストレージ容量不足 | データを削除 |
| `NotFoundError` | データが見つからない | 再読み込み |
| `InvalidStateError` | 不正な状態 | アプリを再起動 |
| `SecurityError` | セキュリティ制限 | HTTPSでアクセス |
| `AbortError` | 操作が中断された | 再試行 |

## データ復旧

### バックアップからの復元

```
復元手順:
1. 設定 → データ管理 → インポート
2. バックアップファイルを選択
3. 復元オプションを設定：
   ☑ 既存データを上書き
   ☐ マージ
4. 「復元を実行」
```

### 緊急時のデータ取り出し

```javascript
// ブラウザコンソールで実行（最終手段）
// IndexedDBからデータを直接取得
const request = indexedDB.open('HierarchiDB');
request.onsuccess = (event) => {
  const db = event.target.result;
  // データベースの内容を確認
  console.log('DB:', db.objectStoreNames);
};
```

### よくある質問（FAQ）

```
Q: データはどこに保存されますか？
A: ブラウザのIndexedDBに保存されます

Q: 複数のデバイスで使えますか？
A: エクスポート/インポートで共有可能です

Q: オフラインで使えますか？
A: 一度読み込めばオフラインでも使用可能です

Q: データの上限はありますか？
A: ブラウザのストレージ容量に依存します（通常数GB）
```
