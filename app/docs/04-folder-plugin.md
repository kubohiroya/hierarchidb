# フォルダープラグイン - 基本的な階層管理

## フォルダープラグインとは

フォルダープラグインは、HierarchiDBの最も基本的なプラグインです。ファイルシステムのようなフォルダ構造でデータを整理できます。

### 主な機能

- 📁 **階層構造の作成**: 無制限の階層深度
- 🏷️ **メタデータ管理**: 説明、タグ、カスタムプロパティ
- 🔍 **高度な検索**: フォルダ内検索、メタデータ検索
- 📋 **テンプレート**: フォルダ構造のテンプレート化

## フォルダの作成

### 基本的なフォルダ作成

1. **親ノードを選択**
2. **右クリック** → 「新規作成」→ 「フォルダ」
3. **フォルダ情報を入力**：

```
フォルダ名: [ドキュメント        ]
説明: [プロジェクトの文書を管理  ]
アイコン: 📁 (選択可能)
色: 🔵 (カスタマイズ可能)
```

### フォルダのプロパティ

#### 基本プロパティ
- **名前**: フォルダの表示名
- **説明**: フォルダの用途や内容の説明
- **作成日時**: 自動設定
- **更新日時**: 自動更新

#### カスタムプロパティ
独自のプロパティを追加可能：

```
カスタムプロパティの例:
- プロジェクトID: PRJ-2024-001
- 担当者: 山田太郎
- 期限: 2024/12/31
- ステータス: 進行中
```

## フォルダの整理

### フォルダ構造の例

効果的なフォルダ構造の例：

```
📁 プロジェクト管理
├── 📁 2024年度
│   ├── 📁 第1四半期
│   │   ├── 📁 プロジェクトA
│   │   │   ├── 📁 企画書
│   │   │   ├── 📁 設計書
│   │   │   └── 📁 議事録
│   │   └── 📁 プロジェクトB
│   └── 📁 第2四半期
├── 📁 テンプレート
│   ├── 📁 プロジェクトテンプレート
│   └── 📁 文書テンプレート
└── 📁 アーカイブ
```

### 命名規則

推奨される命名規則：

1. **日付を含む場合**: `YYYY-MM-DD_名前`
   - 例: `2024-03-15_会議資料`

2. **バージョン管理**: `名前_v1.0`
   - 例: `仕様書_v2.1`

3. **カテゴリ分け**: `[カテゴリ]名前`
   - 例: `[重要]契約書`

## タグとラベル

### タグの追加

フォルダにタグを付けて分類：

1. フォルダを選択
2. 詳細パネルの「タグ」セクション
3. 「+ タグを追加」をクリック
4. タグ名を入力またはリストから選択

```
よく使うタグ:
🔴 緊急 | 🟡 重要 | 🟢 完了
📌 TODO | ⏰ 期限あり | ✅ 承認済み
```

### ラベルによる色分け

視覚的な識別のための色ラベル：

- 🔴 赤: 緊急・重要
- 🟠 オレンジ: 要注意
- 🟡 黄: 確認必要
- 🟢 緑: 完了・承認済み
- 🔵 青: 情報・参考
- 🟣 紫: 個人用

## アクセス権限

### 権限レベル

フォルダごとに設定可能な権限：

| 権限レベル | 閲覧 | 編集 | 削除 | 権限変更 |
|-----------|------|------|------|----------|
| オーナー | ✅ | ✅ | ✅ | ✅ |
| 編集者 | ✅ | ✅ | ❌ | ❌ |
| 閲覧者 | ✅ | ❌ | ❌ | ❌ |
| なし | ❌ | ❌ | ❌ | ❌ |

### 権限の設定

1. フォルダを右クリック
2. 「プロパティ」→「アクセス権限」
3. ユーザーまたはグループを追加
4. 権限レベルを設定

## テンプレート機能

### テンプレートの作成

よく使うフォルダ構造をテンプレート化：

1. **テンプレート化したいフォルダを選択**
2. **右クリック** → 「テンプレートとして保存」
3. **テンプレート名を入力**

### テンプレートの使用

1. **新規作成時に「テンプレートから作成」を選択**
2. **保存済みテンプレートを選択**
3. **必要に応じてカスタマイズ**

```
プロジェクトテンプレートの例:
📁 新規プロジェクト
├── 📁 01_企画
│   ├── 📄 企画書
│   └── 📄 要件定義
├── 📁 02_設計
│   ├── 📄 基本設計
│   └── 📄 詳細設計
├── 📁 03_実装
├── 📁 04_テスト
└── 📁 05_納品
```

## 検索とフィルタリング

### フォルダ内検索

特定のフォルダ以下を検索：

1. フォルダを右クリック
2. 「このフォルダ内を検索」
3. 検索条件を入力

### スマートフォルダ

動的な検索結果をフォルダとして保存：

```
スマートフォルダの条件例:
- 今週更新されたファイル
- 「重要」タグが付いた項目
- 特定の担当者のドキュメント
```

## 一括操作

### 複数フォルダの選択

- **Ctrl + クリック**: 個別選択
- **Shift + クリック**: 範囲選択
- **Ctrl + A**: すべて選択

### 一括操作メニュー

複数選択時の操作：

- 一括移動
- 一括コピー
- 一括削除
- 一括タグ付け
- 一括プロパティ変更

## バックアップと復元

### フォルダのエクスポート

1. フォルダを右クリック
2. 「エクスポート」を選択
3. エクスポート形式を選択：
   - JSON (構造とメタデータを保持)
   - ZIP (ファイル付き)

### フォルダのインポート

1. インポート先を選択
2. 「インポート」→ ファイルを選択
3. インポートオプションを設定：
   - 既存項目の処理（スキップ/上書き/複製）
   - メタデータの扱い

## ベストプラクティス

### 効率的なフォルダ管理のヒント

1. **階層は浅く**: 3-4階層程度に収める
2. **一貫性のある命名**: 規則を決めて守る
3. **定期的な整理**: 不要なフォルダは削除
4. **タグの活用**: 複数の分類軸を活用
5. **テンプレートの利用**: 繰り返し作業を効率化

## トラブルシューティング

### Q: フォルダが作成できない
A: 親ノードの権限を確認してください。編集権限が必要です。

### Q: フォルダが見つからない
A: 検索機能を使用するか、タグでフィルタリングしてください。

### Q: フォルダの移動ができない
A: 移動先の権限と、循環参照になっていないか確認してください。
