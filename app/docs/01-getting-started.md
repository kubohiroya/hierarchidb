# はじめに - HierarchiDBの概要と基本概念

## HierarchiDBとは

HierarchiDBは、階層構造（ツリー構造）を持つデータを直感的に管理できるWebアプリケーションです。ファイルシステムのようなフォルダ構造、プロジェクト管理、地理情報データなど、様々な階層データを統一的に扱うことができます。

### 主な特徴

- 🌲 **直感的なツリー構造**: ドラッグ&ドロップによる簡単な階層管理
- 🔌 **プラグインシステム**: 用途に応じた機能拡張
- 💾 **自動保存**: すべての変更は自動的に保存
- ↩️ **元に戻す/やり直し**: 操作ミスも安心
- 🌍 **多言語対応**: 日本語・英語に対応
- 🔐 **セキュアな認証**: OAuth2.0による安全なログイン

## 基本概念

### ツリー（Tree）
データ全体を表す最上位の構造です。一つのツリーは、プロジェクト全体やシステム全体を表現します。

```
📁 マイプロジェクト（ツリー）
├── 📂 企画書
├── 📂 設計書
└── 📂 リソース
```

### ノード（Node）
ツリーを構成する個々の要素です。フォルダやファイル、プロジェクトタスクなど、様々な種類のノードがあります。

#### ノードの種類
- **フォルダノード**: 他のノードを含むコンテナ
- **プロジェクトノード**: プロジェクト管理用の特殊なフォルダ
- **地図ノード**: 地理情報を含むノード
- **スプレッドシートノード**: 表形式データを管理

### プラグイン（Plugin）
ノードタイプごとの機能を提供するモジュールです。必要に応じて有効化/無効化できます。

## 画面構成

### メイン画面の要素

```
┌─────────────────────────────────────────┐
│  🏠 HierarchiDB    [👤 ユーザー] [⚙️]    │ ← ヘッダーバー
├─────────────────────────────────────────┤
│ [新規] [編集] [削除] [↩️] [↪️]          │ ← ツールバー
├─────────────────────────────────────────┤
│ 📁 マイプロジェクト > 企画書             │ ← パンくずリスト
├─────────────────────────────────────────┤
│ ┌──────────┬────────────────────────┐  │
│ │ ▼ 📁 企画書│  詳細情報パネル       │  │
│ │   📄 概要  │                      │  │ ← メインエリア
│ │   📄 要件  │  選択中: 概要        │  │
│ │ ▶ 📁 資料 │                      │  │
│ └──────────┴────────────────────────┘  │
└─────────────────────────────────────────┘
```

### 主要なUI要素

1. **ヘッダーバー**: アプリケーション名、ユーザー情報、設定メニュー
2. **ツールバー**: よく使う操作へのクイックアクセス
3. **パンくずリスト**: 現在位置の表示とナビゲーション
4. **ツリービュー**: 階層構造の表示と操作
5. **詳細パネル**: 選択中のノードの詳細情報

## 初回起動時の設定

### 1. アプリケーションへのアクセス
ブラウザで HierarchiDB のURLにアクセスします。
```
https://your-domain.com/hierarchidb/
```

### 2. ログイン（オプション）
認証が有効な場合は、Googleアカウントでログインします。

### 3. 言語設定
右上の設定メニューから表示言語を選択できます。
- 🇯🇵 日本語
- 🇺🇸 English

### 4. テーマ選択
ライトモードとダークモードを切り替えられます。

## データの保存について

HierarchiDBでは、すべてのデータはブラウザのIndexedDBに自動保存されます。

### 保存の仕組み
- **自動保存**: 変更は即座に保存
- **ローカル保存**: データはブラウザ内に保存
- **永続化**: ブラウザを閉じてもデータは保持

### 注意事項
- ブラウザのデータをクリアするとデータが失われます
- 異なるブラウザ間でデータは共有されません
- 定期的なエクスポートを推奨します

## よくある質問

### Q: オフラインでも使えますか？
A: はい、一度読み込めばオフラインでも使用できます。

### Q: データのバックアップは？
A: エクスポート機能を使用してJSON形式でバックアップできます。

### Q: 複数人で共有できますか？
A: 現在はローカルデータのみですが、エクスポート/インポートで共有可能です。
