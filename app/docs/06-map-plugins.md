# 地図プラグイン - 地理情報の管理と可視化

## 地図プラグインの概要

HierarchiDBの地図プラグインは、地理情報データの管理と可視化を行うための3つのプラグインで構成されています。

### プラグインの種類

1. **ベースマッププラグイン** 🗺️ - 背景地図の設定
2. **図形プラグイン** 📍 - ポイント、ライン、ポリゴンの作成
3. **スタイルマッププラグイン** 🎨 - データの視覚的表現

## ベースマッププラグイン

### ベースマップの設定

背景となる地図を選択・設定します：

#### 利用可能な地図プロバイダー
```
🗺️ 地図プロバイダー:
• OpenStreetMap (無料)
• 国土地理院地図
• Google Maps (APIキー必要)
• Mapbox (APIキー必要)
```

#### 地図スタイルの選択
```
地図スタイル:
📍 標準: 一般的な地図表示
🛰️ 衛星: 航空写真
🏔️ 地形: 標高情報付き
🌃 ダーク: 夜間モード
```

### 地図の基本操作

#### ナビゲーション
- **パン（移動）**: マウスドラッグ
- **ズーム**: マウスホイール or +/- ボタン
- **回転**: Alt + ドラッグ
- **傾斜**: Ctrl + ドラッグ

#### 表示設定
```
表示オプション:
☑ グリッド線
☑ スケールバー
☑ 方位記号
☑ 座標表示
☐ 3D表示
```

## 図形プラグイン

### ポイント（地点）の作成

#### 単一ポイントの追加
1. ツールバーの「📍 ポイント」を選択
2. 地図上でクリック
3. 情報を入力：

```
ポイント情報:
名称: [東京スカイツリー]
カテゴリ: [観光地]
説明: [高さ634mの電波塔]
座標: 35.7101, 139.8107
```

#### ポイントのスタイル設定
```
マーカースタイル:
アイコン: 📍 🏢 🏠 🏭 🏥 🏫
サイズ: ● ◉ ⬤
色: 🔴 🟠 🟡 🟢 🔵 🟣
```

### ライン（線）の作成

#### 経路の描画
1. 「📏 ライン」ツールを選択
2. クリックで頂点を追加
3. ダブルクリックで完了

```
ライン情報:
名称: [国道1号線]
種別: [道路]
距離: 527.3 km
頂点数: 124
```

#### ラインスタイル
```
線のスタイル:
種類: ─── ┅┅┅ ━━━ ═══
太さ: 細 ━ 中 ━━ 太 ━━━
色: カスタマイズ可能
透明度: 0-100%
```

### ポリゴン（面）の作成

#### エリアの定義
1. 「⬢ ポリゴン」ツールを選択
2. クリックで頂点を追加
3. 始点に戻って閉じる

```
ポリゴン情報:
名称: [中央公園]
種別: [公園]
面積: 25.4 ha
周囲長: 2.1 km
```

#### 塗りつぶしスタイル
```
面のスタイル:
塗りつぶし: ■ 単色 | ▨ パターン | 🌈 グラデーション
境界線: あり/なし
透明度: 0-100%
```

### ジオメトリの編集

#### 頂点の編集
- **頂点の移動**: ドラッグ
- **頂点の追加**: 線上でクリック
- **頂点の削除**: 頂点を右クリック → 削除

#### 変形操作
```
変形ツール:
🔄 回転 | ↔️ 拡大/縮小 | ⤡ 移動
📐 分割 | 🔗 結合 | ✂️ クリップ
```

## スタイルマッププラグイン

### データの視覚化

#### データのインポート
対応フォーマット：
```
📊 対応データ形式:
• CSV (座標付き)
• GeoJSON
• KML/KMZ
• Shapefile
• Excel (座標列含む)
```

#### データマッピング
```
データ列のマッピング:

経度: [Longitude列を選択]
ラベル: [Name列を選択]
値: [Value列を選択]
```

### テーマ別マップ

#### コロプレスマップ（塗り分け地図）
```
値による色分け:
0-25: 🟦 青（低）
26-50: 🟩 緑
51-75: 🟨 黄
76-100: 🟥 赤（高）
```

#### バブルマップ（円の大きさ）
```
値による円サイズ:
小 ● (1-100)
中 ◉ (101-500)
大 ⬤ (501-1000)
特大 ⭕ (1001+)
```

#### ヒートマップ（密度表示）
```
密度表示:
低密度 ░░░░░
中密度 ▒▒▒▒▒
高密度 ▓▓▓▓▓
```

### 分析機能

#### 空間分析
```
分析ツール:
📏 距離測定
📐 面積計算
🎯 バッファ生成
```

#### クラスタリング

## レイヤー管理

### レイヤーの概念

地図上のデータを層として管理：

```
レイヤー構造:
━━━━━━━━━━━━━━━━━
📍 POIレイヤー (最前面)
🛤️ 道路レイヤー
🏘️ 建物レイヤー
🌳 土地利用レイヤー
🗺️ ベースマップ (最背面)
━━━━━━━━━━━━━━━━━
```

### レイヤーの操作

#### 表示/非表示
```
レイヤーパネル:
☑ 観光地 👁️
☑ 交通機関 👁️
☐ 飲食店 👁️‍🗨️
☑ 宿泊施設 👁️
```

#### レイヤーの順序
- ドラッグ&ドロップで順序変更
- 上にあるレイヤーが前面に表示

#### 透明度の調整
各レイヤーの透明度を個別に設定：
```
透明度スライダー:
観光地: ━━━━━━━━━━ 100%
交通機関: ━━━━━━░░░░ 70%
背景地図: ━━━━░░░░░░ 50%
```

## トラブルシューティング

### Q: 地図が表示されない
A: インターネット接続とAPIキーの設定を確認してください。

### Q: データがずれて表示される
A: 座標系（測地系）の設定を確認してください。日本ではJGD2011を推奨。

### Q: 動作が重い
A: 表示するデータ量を減らすか、クラスタリング機能を使用してください。
