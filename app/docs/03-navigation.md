# ナビゲーション - 効率的な移動とショートカット

## ツリー内の移動方法

### パンくずリストを使った移動

画面上部のパンくずリストで現在位置を確認し、上位階層へ素早く移動できます。

```
🏠 ホーム > 📁 マイプロジェクト > 📂 企画書 > 📄 要件定義
           ↑クリックで移動可能
```

### ツリービューでの移動

#### マウス操作
- **シングルクリック**: ノードを選択
- **ダブルクリック**: ノードを展開/折りたたみ、詳細を開く
- **ホイールスクロール**: ツリーを上下にスクロール
- **Shift + ホイール**: 横スクロール（ツリーが横に長い場合）

#### キーボード操作
- **↑ ↓**: 上下のノードへ移動
- **← →**: ノードの展開/折りたたみ、親子間の移動
- **Home**: 最初のノードへ移動
- **End**: 最後のノードへ移動
- **Page Up/Down**: ページ単位でスクロール

### サイドバーナビゲーション

左側のサイドバーから主要な場所へ素早くアクセス：

```
📌 ピン留め
├── 📁 よく使うプロジェクト
├── 📁 共有フォルダ
└── 📁 テンプレート

⏰ 最近使用
├── 📄 議事録_20240315
├── 📄 予算表
└── 📄 タスクリスト

⭐ お気に入り
├── 📁 重要書類
└── 📁 参考資料
```

## ブックマークとピン留め

### ブックマークの追加

1. ノードを右クリック
2. 「⭐ ブックマークに追加」を選択
3. ブックマーク一覧からすぐにアクセス可能

### ピン留め機能

重要なノードをサイドバーにピン留め：

1. ノードを選択
2. 右クリック → 「📌 ピン留め」
3. サイドバーの「ピン留め」セクションに表示

### お気に入りの管理

```
お気に入りの整理:
1. サイドバーの「⭐ お気に入り」を右クリック
2. 「お気に入りを管理」を選択
3. ドラッグ&ドロップで順序変更
4. 不要な項目を削除
```

## 検索とジャンプ

### クイックジャンプ

`Ctrl + G` でクイックジャンプダイアログを開く：

```
ジャンプ先を入力:
> プロジェクト/企画書/要件定義
```

### グローバル検索

`Ctrl + Shift + F` で全ツリー検索：

```
🔍 検索: [予算        ] [検索]

検索結果:
📄 予算表 (マイプロジェクト > 管理 > 財務)
📄 予算計画 (年度計画 > 2024年)
📄 予算見積もり (提案書 > クライアントA)
```

### フィルター検索

検索条件を詳細に設定：

- **ノードタイプ**: フォルダ、ファイル、プロジェクトなど
- **作成日**: 期間を指定
- **更新日**: 最近更新されたものを検索
- **タグ**: 特定のタグが付いたノード

## タブとウィンドウ管理

### タブの操作

複数のノードを別タブで開いて作業：

- **新しいタブで開く**: `Ctrl + クリック`
- **タブを閉じる**: `Ctrl + W`
- **閉じたタブを復元**: `Ctrl + Shift + T`

### 分割ビュー

画面を分割して複数のノードを同時表示：

1. ノードを右クリック
2. 「分割ビューで開く」を選択
3. 縦分割または横分割を選択

```
┌──────────┬──────────┐
│  ノードA  │  ノードB  │
│          │          │
│  内容    │  内容    │
└──────────┴──────────┘
```

## 履歴機能

### 閲覧履歴

最近表示したノードの履歴：

- **戻る**: `Alt + ←` 
- **進む**: `Alt + →`
- **履歴一覧**: `Ctrl + H`

### 操作履歴

実行した操作の履歴を確認：

1. メニュー → 「編集」→ 「操作履歴」
2. 任意の時点まで戻ることが可能

## カスタムショートカット

### ショートカットのカスタマイズ

1. 設定 → キーボードショートカット
2. 変更したいコマンドを選択
3. 新しいキーの組み合わせを入力
4. 「保存」をクリック

### よく使うショートカットの登録

独自のショートカットを作成：

```
例：
- Ctrl + Shift + P: プロジェクト一覧を開く
- Ctrl + Shift + D: 今日の日付でノード作成
- Ctrl + Shift + T: テンプレートから作成
```

## アクセシビリティ機能

### スクリーンリーダー対応

- すべての要素に適切なラベル付け
- ARIAランドマークによる構造化
- キーボードのみでの完全操作

### 高コントラストモード

視認性を高める表示モード：

1. 設定 → アクセシビリティ
2. 「高コントラストモード」を有効化

### フォーカスインジケーター

現在フォーカスされている要素を明確に表示：

- Tab キーでフォーカス移動
- 太い枠線でフォーカス位置を表示

## トラブルシューティング

### Q: ショートカットが効かない
A: 入力フィールドにフォーカスがある場合は、Escキーで解除してください。

### Q: ナビゲーションが遅い
A: 大量のノードを展開している場合は、不要なノードを折りたたんでください。

### Q: 誤って移動してしまった
A: `Alt + ←` で前の場所に戻れます。
