# スプレッドシートプラグイン - 表形式データの管理

## スプレッドシートプラグインとは

スプレッドシートプラグインは、Excelのような表形式でデータを管理・分析できる機能を提供します。CSVファイルのインポート/エクスポート、データの集計、グラフ作成などが可能です。

### 主な機能

- 📊 **表形式編集**: セル単位でのデータ入力・編集
- 📈 **データ分析**: 集計、ソート、フィルタリング
- 📉 **グラフ作成**: 各種チャートの自動生成
- 🔄 **インポート/エクスポート**: CSV、Excel形式対応
- 🧮 **計算式**: セル参照による自動計算

## スプレッドシートの作成

### 新規スプレッドシート

1. **「新規作成」→「スプレッドシート」を選択**
2. **初期設定**：

```
スプレッドシート設定:
名前: [売上管理表]
列数: [10]
行数: [100]
テンプレート: [空白 ▼]
```

### テンプレートの利用

よく使うテンプレート：

```
📊 利用可能なテンプレート:
• 売上管理表
• 在庫管理表
• 顧客リスト
• タスク管理表
• 予算管理表
• 勤怠管理表
```

## データの入力と編集

### セルの操作

#### 基本的な入力

- **シングルクリック**: セル選択
- **ダブルクリック**: 編集モード
- **Enter**: 入力確定・下のセルへ
- **Tab**: 入力確定・右のセルへ
- **Esc**: 編集キャンセル

#### データ型

```
セルのデータ型:
📝 テキスト: 文字列
🔢 数値: 整数・小数
💰 通貨: ¥1,234
📅 日付: 2024/03/15
⏰ 時刻: 14:30
✅ チェックボックス: ☑/☐
📋 リスト: 選択式
```

### 範囲選択

#### 選択方法

- **クリック&ドラッグ**: 矩形選択
- **Shift + クリック**: 範囲選択
- **Ctrl + クリック**: 複数選択
- **Ctrl + A**: 全選択

#### 選択範囲の操作

```
選択範囲に対する操作:
📋 コピー (Ctrl+C)
✂️ カット (Ctrl+X)
📌 ペースト (Ctrl+V)
🗑️ クリア (Delete)
🎨 書式設定
```

## 計算式と関数

### 基本的な計算

#### 四則演算

```
セルA1: 100
セルA2: 50
セルA3: =A1+A2  → 150
セルA4: =A1-A2  → 50
セルA5: =A1*A2  → 5000
セルA6: =A1/A2  → 2
```

### よく使う関数

#### 集計関数

```
=SUM(A1:A10)     // 合計
=AVERAGE(A1:A10) // 平均
=COUNT(A1:A10)   // 個数
=MAX(A1:A10)     // 最大値
=MIN(A1:A10)     // 最小値
```

#### 文字列関数

```
=CONCAT(A1,B1)   // 文字列結合
=LEFT(A1,3)      // 左から3文字
=RIGHT(A1,2)     // 右から2文字
=LEN(A1)         // 文字数
=UPPER(A1)       // 大文字変換
```

#### 条件関数

```
=IF(A1>100,"高","低")        // 条件分岐
=COUNTIF(A1:A10,">50")       // 条件付きカウント
=SUMIF(A1:A10,">50",B1:B10)  // 条件付き合計
```

### セル参照

#### 参照の種類

```
相対参照: A1 (コピー時に自動調整)
絶対参照: $A$1 (固定)
混合参照: $A1, A$1 (列または行を固定)
```

## データの整理と分析

### ソート（並び替え）

#### 単一列ソート

1. ソートしたい列を選択
2. 「データ」→「昇順/降順」

#### 複数列ソート

```
ソート優先順位:
第1キー: [部門 ▼] [昇順]
第2キー: [売上 ▼] [降順]
第3キー: [日付 ▼] [昇順]
```

### フィルタリング

#### オートフィルター

```
フィルター条件:
部門: ☑ 営業部 ☑ 開発部 ☐ 総務部
売上: [100万以上]
期間: [2024年3月]
```

#### カスタムフィルター

```
詳細条件:
売上 >= 100万 AND 売上 <= 500万
OR
部門 = "特別プロジェクト"
```

### ピボットテーブル

データの多角的な集計：

```
ピボットテーブル設定:
行: [部門]
列: [月]
値: [売上の合計]

結果:
        1月    2月    3月    合計
営業部   100    150    200    450
開発部   80     90     110    280
総務部   50     60     70     180
```

## グラフとチャート

## トラブルシューティング

### Q: 計算式が動作しない

A: セルの参照が正しいか、循環参照がないか確認してください。

### Q: グラフが更新されない

A: データ範囲を再選択するか、グラフを作り直してください。

### Q: インポートしたデータが文字化けする

A: 文字コードをShift-JISまたはUTF-8に変更してインポートし直してください。
