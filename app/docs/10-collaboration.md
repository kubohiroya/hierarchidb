# コラボレーション - 共同作業機能

## コラボレーション機能の概要

HierarchiDBのコラボレーション機能を使用すると、チームメンバーと効率的に情報を共有し、共同でプロジェクトを進めることができます。

### 主な機能

```
👥 コラボレーション機能:
• リアルタイム共同編集
• コメント・ディスカッション
• 変更履歴とバージョン管理
• 権限管理とアクセス制御
• 通知とアクティビティ追跡
```

## ユーザー管理

チームメンバーを招待：

```
招待設定:

役割: [編集者 ▼]

### ユーザー権限

#### 権限レベル

| 役割    | 閲覧 | 編集 | 削除 | 共有 | 管理 |
|-------|----|----|----|----|----|
| オーナー  | ✅  | ✅  | ✅  | ✅  | ✅  |
| 管理者   | ✅  | ✅  | ✅  | ✅  | ⚠️ |
| 編集者   | ✅  | ✅  | ❌  | ⚠️ | ❌  |
| コメンター | ✅  | ❌  | ❌  | ❌  | ❌  |
| 閲覧者   | ✅  | ❌  | ❌  | ❌  | ❌  |

⚠️ = 制限付き

## リアルタイム共同編集

### 同時編集

複数ユーザーによる同時作業：

```
編集中のユーザー:
━━━━━━━━━━━━━━━━━━━━━━━━
👤 山田 - ノード「企画書」を編集中...
   カーソル位置: 3行目
👤 佐藤 - ノード「予算表」を閲覧中
👤 鈴木 - ノード「タスクリスト」を編集中...
━━━━━━━━━━━━━━━━━━━━━━━━
```

### カーソルと選択範囲

他ユーザーの操作を可視化：

```
リアルタイム表示:
• 各ユーザーのカーソル（色分け）
• 選択範囲のハイライト
• 入力中のテキスト
• スクロール位置
```

### 競合の解決

同時編集時の競合処理：

```
競合検出:
⚠️ 同じ箇所を編集しています

解決オプション:
● 自分の変更を優先
○ 相手の変更を優先
○ 両方の変更をマージ
○ 手動で解決

[プレビュー] [適用]
```

ノードにコメントを付与：

```
