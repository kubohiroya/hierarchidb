# HierarchiDB ユーザーマニュアル

## このマニュアルについて

HierarchiDBは、階層構造（ツリー構造）を持つデータを効率的に管理・操作するためのWebアプリケーションです。本マニュアルでは、HierarchiDBの基本的な使い方から応用的な活用方法まで、順を追って説明します。
