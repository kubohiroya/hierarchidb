# インポート・エクスポート - データの入出力

## 概要

HierarchiDBのインポート・エクスポート機能を使用すると、外部システムとのデータ連携、バックアップの作成、他のユーザーとのデータ共有が可能です。

### 対応フォーマット

```
📥 インポート可能:
• JSON (HierarchiDB形式)
• CSV (表形式データ)
• Excel (.xlsx)
• XML
• GeoJSON (地理データ)

📤 エクスポート可能:
• JSON (完全バックアップ)
• CSV (表形式出力)
• Excel (フォーマット付き)
• PDF (印刷用)
• HTML (Web公開用)
```

## インポート機能

### インポートの開始

1. **メニュー → ファイル → インポート**
2. **インポート方法を選択**：

```
インポート方法:
📁 ファイルを選択
📋 クリップボードから貼り付け
🌐 URLから取得
🔗 API連携
```

### ファイル形式別インポート

#### JSON形式

HierarchiDBのネイティブ形式：

```json
{
  "version": "1.0",
  "tree": {
    "id": "tree-001",
    "name": "マイプロジェクト",
    "nodes": [
      {
        "id": "node-001",
        "type": "folder",
        "name": "ドキュメント",
        "children": []
      }
    ]
  }
}
```

設定オプション：
```
JSONインポート設定:
☑ 構造を保持
☑ メタデータを含む
☐ IDを再生成
☑ タイムスタンプを更新
```

#### CSV形式

表形式データのインポート：

```csv
名前,タイプ,親フォルダ,説明,作成日
企画書,document,/ドキュメント,プロジェクト企画,2024-03-15
議事録,document,/会議,定例会議メモ,2024-03-14
```

マッピング設定：
```
列のマッピング:
名前 → [ノード名]
タイプ → [ノードタイプ]
親フォルダ → [親ノードパス]
説明 → [説明]
作成日 → [作成日時]
```

#### Excel形式

複数シートの処理：

```
シートの選択:
☑ Sheet1: プロジェクト一覧
☑ Sheet2: タスクリスト
☐ Sheet3: 集計データ

インポート方法:
● 各シートを別ノードとして
○ シートを結合して1つのノードに
```

### インポートオプション

#### 重複処理

既存データとの重複時の処理：

```
重複時の処理:
● スキップ (既存を保持)
○ 上書き (新規で置換)
○ 両方保持 (名前に番号付加)
○ マージ (データを結合)
```

#### データ検証

インポート前の検証：

```
検証項目:
✅ データ形式の確認
✅ 必須フィールドのチェック
⚠️ 参照整合性の確認
✅ 文字コードの判定
```

### バッチインポート

複数ファイルの一括インポート：

```
バッチインポート:
ファイル一覧:
📄 project_2024.json ✅
📄 tasks.csv ✅
📄 locations.geojson ✅

処理順序: ドラッグで変更可能
エラー時: ○ 中断 ● スキップして続行
```

## エクスポート機能

### エクスポートの開始

1. **エクスポート対象を選択**
2. **メニュー → ファイル → エクスポート**
3. **エクスポート設定**：

```
エクスポート範囲:
● ツリー全体
○ 選択ノード以下
○ 選択ノードのみ
○ フィルター結果
```

### 形式別エクスポート

#### JSON形式（完全バックアップ）

```
JSONエクスポート設定:
☑ ノード構造
☑ メタデータ
☑ プラグインデータ
☑ ユーザー設定
☑ 履歴情報
圧縮: ☑ gzip圧縮
```

#### CSV形式（表データ）

```
CSVエクスポート設定:
区切り文字: [カンマ ▼]
文字コード: [UTF-8 ▼]
ヘッダー: ☑ 含める
引用符: ["ダブルクォート" ▼]
```

出力例：
```csv
"ID","名前","タイプ","パス","更新日時"
"001","企画書","document","/プロジェクト/ドキュメント","2024-03-15 10:30"
"002","設計書","document","/プロジェクト/ドキュメント","2024-03-16 14:20"
```

#### PDF形式（印刷・共有用）

```
PDFエクスポート設定:

内容:
☑ ツリー構造図
☑ ノード詳細
```

#### HTML形式（Web公開）

```

インタラクティブ: ☑
ナビゲーション: ☑ 含める
```


## データ変換

### フィールドマッピング

異なる形式間でのフィールド対応：

```
フィールドマッピング:
HierarchiDB → 外部システム
--------------------------------
node.name → title
node.description → summary
node.created_at → creation_date
node.tags → categories
```

### データ変換ルール

```
変換ルール:
日付形式: YYYY-MM-DD → MM/DD/YYYY
数値: カンマ区切り → 小数点
テキスト: 全角 → 半角
改行: LF → CRLF
```

### カスタム変換スクリプト

JavaScript による変換処理：

```javascript
// カスタム変換例
function transform(node) {
  return {
    id: node.id,
    title: node.name.toUpperCase(),
    date: new Date(node.created_at).toLocaleDateString('ja-JP'),
    status: node.completed ? '完了' : '進行中'
  };
}
```

## トラブルシューティング

### インポートエラー

```
よくあるエラーと対処法:
━━━━━━━━━━━━━━━━━━━━━━━━
❌ "Invalid format"
→ ファイル形式を確認

❌ "Encoding error"
→ 文字コードをUTF-8に変更

❌ "Size limit exceeded"
→ ファイルを分割してインポート

❌ "Duplicate ID"
→ ID再生成オプションを有効化
```

### エクスポートエラー

```
エラー対処:
━━━━━━━━━━━━━━━━━━━━━━━━
⚠️ ディスク容量不足
→ 不要なファイルを削除

⚠️ 権限エラー
→ 書き込み権限を確認

⚠️ ネットワークエラー
→ 接続を確認して再試行
```
