# 基本操作 - ツリーとノードの操作

## ツリーの作成と管理 {#create-tree}

### 新しいツリーを作成する

1. **ホーム画面から開始**
    - アプリケーションを起動すると、ツリー選択画面が表示されます
    - 「新規ツリー作成」ボタンをクリック

2. **ツリー情報の入力**
   ```
   ツリー名: マイプロジェクト
   説明: プロジェクト管理用のツリー（オプション）
   ```

3. **作成完了**
    - 「作成」ボタンをクリックでツリーが作成されます
    - 自動的に新しいツリーが開きます

### 既存のツリーを開く

ホーム画面のツリー一覧から選択してクリックします。

```
📊 最近使用したツリー
├── 📁 マイプロジェクト（最終更新: 1時間前）
├── 📁 ドキュメント管理（最終更新: 昨日）
└── 📁 リソース管理（最終更新: 3日前）
```

## ノードの基本操作 {#node-operations}

### ノードの追加

#### 方法1: ツールバーから

1. 親となるノードを選択
2. ツールバーの「➕ 新規」ボタンをクリック
3. ノードタイプを選択（フォルダ、プロジェクトなど）
4. 名前を入力して「作成」

#### 方法2: 右クリックメニュー

1. 親ノードを右クリック
2. 「新規作成」→ ノードタイプを選択
3. 名前を入力

#### 方法3: キーボードショートカット

- `Ctrl + N` (Windows) / `Cmd + N` (Mac): 新規ノード作成

### ノードの編集

#### 名前の変更

1. ノードを選択
2. `F2`キーを押すか、ノード名をダブルクリック
3. 新しい名前を入力
4. `Enter`で確定、`Esc`でキャンセル

#### プロパティの編集

1. ノードを選択
2. 右側の詳細パネルで編集
3. 変更は自動保存されます

### ノードの削除

#### 削除操作

1. 削除したいノードを選択
2. 以下のいずれかの方法で削除：
    - `Delete`キーを押す
    - ツールバーの「🗑️ 削除」ボタン
    - 右クリック → 「削除」

#### ゴミ箱機能

- 削除されたノードは「ゴミ箱」に移動
- ゴミ箱から復元可能
- ゴミ箱を空にすると完全削除

### ノードの移動

#### ドラッグ&ドロップ

1. 移動したいノードをクリック&ホールド
2. 移動先の親ノードまでドラッグ
3. ドロップして移動完了

#### カット&ペースト

1. ノードを選択して `Ctrl + X` (カット)
2. 移動先の親ノードを選択
3. `Ctrl + V` (ペースト)

### ノードのコピー

1. コピーしたいノードを選択
2. `Ctrl + C` (コピー)
3. 貼り付け先の親ノードを選択
4. `Ctrl + V` (ペースト)

## 複数選択と一括操作

### 複数ノードの選択

#### 連続選択

- `Shift + クリック`: 範囲選択
- 最初のノードをクリック → Shiftを押しながら最後のノードをクリック

#### 個別選択

- `Ctrl + クリック` (Windows) / `Cmd + クリック` (Mac): 個別に追加/削除

#### すべて選択

- `Ctrl + A`: 現在のレベルのすべてのノードを選択

### 一括操作

選択した複数のノードに対して：

- **一括削除**: `Delete`キー
- **一括移動**: ドラッグ&ドロップ
- **一括コピー**: `Ctrl + C` → `Ctrl + V`

## 元に戻す・やり直し（Undo/Redo）

### Undo（元に戻す）

- **ショートカット**: `Ctrl + Z`
- **ツールバー**: ↩️ ボタン
- 直前の操作を取り消します

### Redo（やり直し）

- **ショートカット**: `Ctrl + Y` または `Ctrl + Shift + Z`
- **ツールバー**: ↪️ ボタン
- 取り消した操作を再実行します

### 履歴の制限

- 最大100操作まで記録
- ブラウザを閉じると履歴はクリア

## データ管理 {#data-management}

### 自動保存

- すべての変更は自動的に保存
- 保存インジケーター: 💾 （保存中） → ✅ （保存完了）

### 手動保存（エクスポート）

1. メニュー → 「ファイル」→ 「エクスポート」
2. 形式を選択（JSON、CSV）
3. ファイルがダウンロードされます

### データの復元（インポート）

1. メニュー → 「ファイル」→ 「インポート」
2. ファイルを選択またはドラッグ&ドロップ
3. インポート設定を確認
4. 「インポート」ボタンをクリック

## 検索機能

### クイック検索

1. ツールバーの検索ボックスに入力
2. リアルタイムで検索結果を表示
3. Enterキーで次の結果へジャンプ

### 詳細検索

1. `Ctrl + F` で検索パネルを開く
2. 検索条件を設定：
    - 検索範囲（現在のノード以下/ツリー全体）
    - 大文字小文字の区別
    - 正規表現の使用

## 表示オプション

### ツリーの展開/折りたたみ

#### 個別操作

- ▶ クリック: ノードを展開
- ▼ クリック: ノードを折りたたむ

#### 一括操作

- 右クリック → 「すべて展開」
- 右クリック → 「すべて折りたたむ」

### ソート（並び替え）

1. ツールバーの「並び替え」メニュー
2. ソート条件を選択：
    - 名前順（A-Z / Z-A）
    - 作成日順
    - 更新日順
    - タイプ別

### フィルタリング

1. ツールバーの「フィルター」アイコン
2. 表示するノードタイプを選択
3. 条件に一致するノードのみ表示

## よくあるトラブルと解決方法

### Q: 変更が保存されない

A: ブラウザのプライベートモードでは保存されません。通常モードで使用してください。

### Q: ノードが見つからない

A: 検索機能を使用するか、「すべて展開」で全ノードを表示してください。

### Q: 操作を間違えた

A: `Ctrl + Z` で元に戻すことができます。
