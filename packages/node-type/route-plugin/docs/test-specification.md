# Route Plugin テスト仕様書

## 概要

Route Pluginのユーザシナリオベースのテスト仕様書です。経路管理と最適化に特化したテストケースを定義しています。

## ユーザシナリオ

### 1. 経路作成シナリオ

交通計画担当者が各種交通モードの経路を作成する。

#### テストケース 1.1: 基本経路作成（直線接続）
- 出発地点と到着地点を設定
- 交通モード（道路、鉄道等）を選択
- 直線経路の自動生成
- 期待結果: RouteEntityが正常に作成され、lineGeometryが生成される

#### テストケース 1.2: ウェイポイント経由の経路作成
- 複数の経由地点を含む経路設定
- Location plugin参照とカスタム座標の混在
- OSMルーティング方式での経路生成
- 期待結果: 全ウェイポイントを通る最適経路が生成される

#### テストケース 1.3: 交通モード別経路作成
- 航空路、海路、パイプライン等の特殊経路
- 各モード固有の生成アルゴリズム適用
- 運行スケジュールとオペレーター情報設定
- 期待結果: モード固有の属性が正しく設定される

### 2. 経路編集シナリオ

既存経路の最適化と設定変更を行う。

#### テストケース 2.1: 経路最適化（WorkingCopyパターン）
- 既存経路のWorkingCopyを作成
- ウェイポイントの追加・削除・並び替え
- 交通モードの変更と再計算
- 期待結果: WorkingCopyで変更が適用され、距離・時間が更新される

#### テストケース 2.2: 経路スタイル設定編集
- 路線の色、幅、透明度設定
- アニメーション効果の有効化
- ダッシュライン（破線）パターンの設定
- 期待結果: 視覚化設定が正しく保存される

#### テストケース 2.3: 運行情報更新
- 運行スケジュール（CRONパターン）の設定
- 運行頻度と平均間隔の更新
- 運行会社情報と路線番号の管理
- 期待結果: 運行メタデータが正しく更新される

### 3. 経路バッチ処理シナリオ

複数経路の一括操作と ネットワーク分析。

#### テストケース 3.1: 交通ネットワーク一括生成
- 複数の拠点間での全対全経路生成
- 異なる交通モードでの同一区間比較
- バッチ処理での進捗管理
- 期待結果: 全拠点間の最適経路が効率的に生成される

#### テストケース 3.2: 経路統計と分析
- 交通モード別の統計情報生成
- 接続性分析（連結されたロケーション数）
- 処理状況の監視とエラー処理
- 期待結果: 包括的な経路ネットワーク統計が生成される

#### テストケース 3.3: 経路データのクリーンアップ
- 重複経路の検出と統合
- 未使用経路の一括削除
- 関連データ（キャッシュ）の整理
- 期待結果: データベースが最適化され、整合性が保たれる

## 技術的検証項目

- WorkingCopyパターンでの経路再計算
- Location plugin連携の動作確認
- 経路生成アルゴリズムの精度検証
- 大量経路での処理性能測定
- エラーハンドリングの網羅性
