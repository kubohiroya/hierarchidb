# @hierarchidb/shape-store

最終更新: 2026-04-05

HierarchiDB の Shape データストアパッケージ。Dexie（IndexedDB）ベースの Shape フィーチャ・ベクトルタイル・ビルドセッション・キャッシュの永続化を提供する。shape-plugin の Worker 層が使用する。

## 依存関係

`@hierarchidb/core-types`, `@hierarchidb/gis-sdk`, `@hierarchidb/tabular-store`, `@hierarchidb/shape-api`, `@hierarchidb/util`, `@hierarchidb/vectortile-store`

## 関連パッケージ

- [`@hierarchidb/shape-api`](../shape-api/) — Shape API 型定義
- [`@hierarchidb/vectortile-store`](../vectortile-store/) — ベクトルタイルストア
