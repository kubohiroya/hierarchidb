# @hierarchidb/shape-store

Last updated: 2026-04-05

Shape data store package for HierarchiDB. Provides Dexie (IndexedDB)-based persistence for Shape features, vector tiles, build sessions, and cache. Used by the shape-plugin Worker layer.

## Dependencies

`@hierarchidb/core-types`, `@hierarchidb/gis-sdk`, `@hierarchidb/tabular-store`, `@hierarchidb/shape-api`, `@hierarchidb/util`, `@hierarchidb/vectortile-store`

## Related Packages

- [`@hierarchidb/shape-api`](../shape-api/) — Shape API type definitions
- [`@hierarchidb/vectortile-store`](../vectortile-store/) — Vector tile store
