# @hierarchidb/download

最終更新: 2026-04-05

HierarchiDB のネットワークダウンロードサービスパッケージ。`FetchNetworkPort`（ホスト単位の同時接続管理、上限 4）、CORS プロキシ対応、ダウンロード進捗追跡を提供する。

## 依存関係

`@hierarchidb/util`, `@hierarchidb/auth`, `@hierarchidb/auth-api`

## 関連パッケージ

- [`@hierarchidb/auth`](../auth/) — 認証基盤（fetchWithAuth）
- [`@hierarchidb/chunk-store`](../chunk-store/) — ダウンロードデータの永続化
