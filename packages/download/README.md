# @hierarchidb/download

Last updated: 2026-04-05

Network download service for HierarchiDB. Provides `FetchNetworkPort` (per-host connection management with concurrency limit of 4), CORS proxy support, and download progress tracking.

## Dependencies

`@hierarchidb/util`, `@hierarchidb/auth`, `@hierarchidb/auth-api`

## Related Packages

- [`@hierarchidb/auth`](../auth/) — Authentication (fetchWithAuth)
- [`@hierarchidb/chunk-store`](../chunk-store/) — Download data persistence
