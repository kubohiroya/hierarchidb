# @hierarchidb/gis-sdk

Last updated: 2026-04-05

GIS SDK package for HierarchiDB. Provides the geographic information processing foundation including geometry configuration types (simplification parameters, zoom band settings), coordinate transformations, and spatial computation utilities. Used by shape-plugin and route-plugin build pipelines.

## Dependencies

`@hierarchidb/core-types`, `@hierarchidb/shape-api`, `@hierarchidb/util`, `@hierarchidb/vectortile-store`

## Related Packages

- [`@hierarchidb/shape-store`](../shape-store/) — Shape data store
- [`@hierarchidb/vectortile-store`](../vectortile-store/) — Vector tile store
