# @hierarchidb/gis-sdk

最終更新: 2026-04-05

HierarchiDB の GIS SDK パッケージ。地理情報処理の基盤として、ジオメトリ設定型（簡略化パラメータ、ズーム帯設定）、座標変換、空間演算ユーティリティを提供する。shape-plugin / route-plugin のビルドパイプラインが使用する。

## 依存関係

`@hierarchidb/core-types`, `@hierarchidb/shape-api`, `@hierarchidb/util`, `@hierarchidb/vectortile-store`

## 関連パッケージ

- [`@hierarchidb/shape-store`](../shape-store/) — Shape データストア
- [`@hierarchidb/vectortile-store`](../vectortile-store/) — ベクトルタイルストア
