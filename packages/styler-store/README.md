# @hierarchidb/styler-store

Last updated: 2026-04-05

Styler data store package for HierarchiDB. Provides the Dexie-based `StylerDB` for persisting StyleRecord (nodeId, keyColumn, valueColumn, paintExpression, etc.). Used by the styler-plugin Worker layer.

## Dependencies

`@hierarchidb/core-types`, `@hierarchidb/plugin-base`, `@hierarchidb/style-api`, `@hierarchidb/spreadsheet-store`, `@hierarchidb/ui-map`, `@hierarchidb/util`

## Related Packages

- [`@hierarchidb/style-api`](../style-api/) — Style API type definitions
- [`@hierarchidb/spreadsheet-store`](../spreadsheet-store/) — Spreadsheet data store
