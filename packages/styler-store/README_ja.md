# @hierarchidb/styler-store

最終更新: 2026-04-05

HierarchiDB の Styler データストアパッケージ。Dexie ベースの `StylerDB` を提供し、StyleRecord（nodeId、keyColumn、valueColumn、paintExpression 等）の永続化を管理する。styler-plugin の Worker 層が使用する。

## 依存関係

`@hierarchidb/core-types`, `@hierarchidb/plugin-base`, `@hierarchidb/style-api`, `@hierarchidb/spreadsheet-store`, `@hierarchidb/ui-map`, `@hierarchidb/util`

## 関連パッケージ

- [`@hierarchidb/style-api`](../style-api/) — Style API 型定義
- [`@hierarchidb/spreadsheet-store`](../spreadsheet-store/) — Spreadsheet データストア
