# @hierarchidb/vectortile-store

Last updated: 2026-04-05

Vector tile store package for HierarchiDB. Provides the `VectorTileStore` interface and Dexie-based implementation. Manages MVT binary data persistence, retrieval, and deletion. Used by shape-plugin and route-plugin.

## Dependencies

`@hierarchidb/shape-api`, `@hierarchidb/util`
