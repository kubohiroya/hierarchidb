# @hierarchidb/vectortile-store

最終更新: 2026-04-05

HierarchiDB のベクトルタイルストアパッケージ。`VectorTileStore` インターフェースと Dexie ベースの実装を提供する。MVT バイナリデータの永続化・取得・削除を管理する。shape-plugin / route-plugin が使用する。

## 依存関係

`@hierarchidb/shape-api`, `@hierarchidb/util`

## 関連パッケージ

- [`@hierarchidb/gis-sdk`](../gis-sdk/) — GIS SDK
- [`@hierarchidb/vt-orchestrator`](../vt-orchestrator/) — ベクトルタイルオーケストレータ
