# @hierarchidb/route-api

最終更新: 2026-04-05

HierarchiDB の Route API 型定義パッケージ。RouteEntity、RouteBuildConfig、RouteMode、OD ペア型等を提供する。route-plugin と route-store の間の契約を定義する。

## 依存関係

`@hierarchidb/build-api`, `@hierarchidb/core-types`, `@hierarchidb/gis-sdk`, `@hierarchidb/location-api`, `@hierarchidb/tree-api`

## 関連パッケージ

- [`@hierarchidb/route-store`](../route-store/) — Route データストア
- [`@hierarchidb/route-engine`](../route-engine/) — ルート生成エンジン
