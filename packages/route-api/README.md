# @hierarchidb/route-api

Last updated: 2026-04-05

Route API type definitions for HierarchiDB. Provides RouteEntity, RouteBuildConfig, RouteMode, OD pair types, etc. Defines the contract between route-plugin and route-store.

## Dependencies

`@hierarchidb/build-api`, `@hierarchidb/core-types`, `@hierarchidb/gis-sdk`, `@hierarchidb/location-api`, `@hierarchidb/tree-api`

## Related Packages

- [`@hierarchidb/route-store`](../route-store/) — Route data store
- [`@hierarchidb/route-engine`](../route-engine/) — Route generation engine
