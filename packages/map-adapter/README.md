# @hierarchidb/map-adapter

Last updated: 2026-04-05

Map adapter package for HierarchiDB. Provides an adapter layer between MapLibre GL JS and HierarchiDB data sources. Manages map source (`map-source`) registration and lifecycle.

## Dependencies

`@hierarchidb/map-source`, `@hierarchidb/util`

## Related Packages

- [`@hierarchidb/map-source`](../map-source/) — Map source definitions
- [`@hierarchidb/ui-map`](../ui/map/) — Map UI components
