# @hierarchidb/map-adapter

最終更新: 2026-04-05

HierarchiDB の地図アダプタパッケージ。MapLibre GL JS と HierarchiDB のデータソース間のアダプタ層を提供する。地図ソース（`map-source`）の登録・管理を行う。

## 依存関係

`@hierarchidb/map-source`, `@hierarchidb/util`

## 関連パッケージ

- [`@hierarchidb/map-source`](../map-source/) — 地図ソース定義
- [`@hierarchidb/ui-map`](../ui/map/) — 地図 UI コンポーネント
