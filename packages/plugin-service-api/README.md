# @hierarchidb/plugin-service-api

Last updated: 2026-04-05

A transitional re-export package for HierarchiDB plugin service APIs. Aggregates and re-exports from `plugin-base`, `style-api`, `shape-api`, `location-api`, and `route-api`.

> **Note**: This package is deprecated and transitional. New code should import directly from the individual API packages.

## Re-export Sources

| Package | Contents |
| --- | --- |
| [`@hierarchidb/plugin-base`](../plugin-base/) | PluginManifest, PluginStepRegistry, etc. |
| [`@hierarchidb/style-api`](../style-api/) | StyleRecord, StyleDescriptor, etc. |
| [`@hierarchidb/shape-api`](../shape-api/) | ShapeEntity types, etc. |
| [`@hierarchidb/location-api`](../location-api/) | LocationEntity types, etc. |
| [`@hierarchidb/route-api`](../route-api/) | RouteEntity types, etc. |
