# @hierarchidb/shape-api

Last updated: 2026-04-05

Shape API type definitions for HierarchiDB. Provides type definitions for ShapeEntity, ShapeFeaturePayload, build configuration, data source types, etc. Defines the contract between shape-plugin and shape-store.

## Dependencies

`@hierarchidb/core-types`, `@hierarchidb/util`
