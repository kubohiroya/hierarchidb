# @hierarchidb/shape-api

最終更新: 2026-04-05

HierarchiDB の Shape API 型定義パッケージ。ShapeEntity、ShapeFeaturePayload、ビルド設定型、データソース型等の型定義を提供する。shape-plugin と shape-store の間の契約を定義する。

## 依存関係

`@hierarchidb/core-types`, `@hierarchidb/util`

## 関連パッケージ

- [`@hierarchidb/shape-store`](../shape-store/) — Shape データストア（実装）
- [`@hierarchidb/core-types`](../core-types/) — 共有型定義
