# @hierarchidb/components

Last updated: 2026-04-05

Shared UI component library for HierarchiDB. Provides common UI components (notifications, confirmations, etc.) used across the application and plugins.

## Dependencies

`@hierarchidb/ui-dialog`, `@hierarchidb/ui-i18n`

## Related Packages

- [`@hierarchidb/ui-dialog`](../ui/dialog/) — Dialog base
- [`@hierarchidb/plugin-ui-host`](../plugin-ui-host/) — Plugin dialog host (uses components)
