# @hierarchidb/components

最終更新: 2026-04-05

HierarchiDB の共有 UI コンポーネントライブラリ。アプリケーション・プラグイン全体で使用される共通 UI コンポーネント（通知、確認ダイアログ等）を提供する。

## 依存関係

`@hierarchidb/ui-dialog`, `@hierarchidb/ui-i18n`

## 関連パッケージ

- [`@hierarchidb/ui-dialog`](../ui/dialog/) — ダイアログ基盤
- [`@hierarchidb/plugin-ui-host`](../plugin-ui-host/) — プラグインダイアログホスト（components を使用）
