# Styler 色分類アルゴリズム UI 実装ドキュメント

## 概要

Styler プラグインに、データ特性を分析して最適な色分類アルゴリズムを自動推奨する機能を実装しました。この機能により、ユーザーは自分のデータに最も適した視覚表現を簡単に選択できるようになります。

## 実装内容

### 1. データ分析エンジン (`dataAnalysis.ts`)

データの統計的特性を分析し、各アルゴリズムの適合度を計算する機能を実装：

- **統計計算**: 平均、中央値、標準偏差、歪度、尖度、四分位数
- **分布判定**: 正規分布、歪んだ分布、二峰性分布、一様分布
- **外れ値検出**: IQR法による外れ値の検出
- **自然な区切り検出**: ヒストグラムの谷間検出によるクラスター判定
- **適合度スコアリング**: データ特性に基づく各アルゴリズムのスコア計算

#### 詳細な説明セクション

各アルゴリズムの特徴と用途を詳しく説明：

- **線形補間**: 連続的な変化の表現
- **分位数分類**: データの偏りへの対応
- **自然分類（Jenks）**: データの自然な区切りの発見
- **等間隔分類**: 値範囲の均等分割

## アルゴリズム推奨ロジック

### 推奨基準

1. **正規分布データ** → 等間隔分類を推奨
   - 理由: データが均等に分布しているため、等間隔が最も直感的

2. **歪んだ分布** → 分位数分類を推奨
   - 理由: 各クラスの要素数を均等にすることで、バランスの取れた表現

3. **自然なクラスター** → Jenks自然分類を推奨
   - 理由: データ内の自然な境界を最適に表現

4. **外れ値を含む** → 分位数分類を推奨
   - 理由: 外れ値の影響を受けにくい

5. **離散的な値** → Jenks自然分類を推奨
   - 理由: 少ない値を意味のあるグループに分類

### スコアリング計算

```typescript
// 基本スコア: 50点
// データ特性に応じて加減点

if (stats.distribution === 'normal') {
  scores.equal += 35;      // 等間隔が最適
  scores.linear += 25;     // 線形も良い
}

if (stats.hasOutliers) {
  scores.quantile += 20;   // 分位数が外れ値に強い
  scores.equal -= 15;      // 等間隔は影響受ける
}

if (hasNaturalBreaks) {
  scores.jenks += 40;      // Jenksが最適
}
```

## 使用方法

### Step 5: スタイルマッピング設定

1. **データ選択時**: 
   - 値列を選択すると自動的にデータ分析が実行される
   - 分析完了後、推奨アルゴリズムがアラートで表示

2. **推奨の適用**:
   - 「適用」ボタンで推奨設定を即座に適用
   - または手動で別のアルゴリズムを選択

3. **適合度の確認**:
   - 各アルゴリズムボタンのチップで適合度を確認
   - 緑: 70%以上（推奨）
   - グレー: 40-70%（可能）
   - 赤: 40%未満（非推奨）

4. **詳細情報**:
   - 選択したアルゴリズムの詳細説明を確認
   - データでの適合度を数値で確認

## 技術的詳細

### パフォーマンス最適化

- データ分析は非同期で実行（300ms遅延）
- 大規模データ（>10,000件）の場合はサンプリング適用
- 分析結果はメモ化してキャッシュ

### 型安全性

```typescript
interface DataAnalysisResult {
  statistics: DataStatistics;
  recommendation: AlgorithmRecommendation;
  hasNaturalBreaks: boolean;
  clusterCount?: number;
}

interface AlgorithmRecommendation {
  algorithm: ColorAlgorithm;
  confidence: number;  // 0-1
  reasoning: string;
  suitability: {
    linear: number;    // 0-100
    quantile: number;  // 0-100
    jenks: number;     // 0-100
    equal: number;     // 0-100
  };
}
```

### エラーハンドリング

- 数値でないデータは自動的にフィルタリング
- 空データの場合はデフォルト値を返す
- 分析失敗時は推奨を表示しない
