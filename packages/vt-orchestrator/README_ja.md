# @hierarchidb/vt-orchestrator

最終更新: 2026-04-05

HierarchiDB のベクトルタイルオーケストレータパッケージ（Worker 側）。`runStageTasks`（ステージベースのタスク実行）、`VtTaskQueueDb`（タスクキューの Dexie 永続化）を提供する。shape-plugin / route-plugin のビルドパイプラインが使用する。

## 依存関係

`@hierarchidb/build-api`, `@hierarchidb/chunk-store`, `@hierarchidb/core-types`, `@hierarchidb/gis-sdk`, `@hierarchidb/plugin-service-api`, `@hierarchidb/shape-api`, `@hierarchidb/util`, `@hierarchidb/shape-store`

## 関連パッケージ

- [`@hierarchidb/vectortile-store`](../vectortile-store/) — ベクトルタイルストア
- [`@hierarchidb/build`](../build/) — ビルドシステム基盤
