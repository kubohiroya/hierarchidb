# @hierarchidb/vt-orchestrator

Last updated: 2026-04-05

Vector tile orchestrator package (Worker side) for HierarchiDB. Provides `runStageTasks` (stage-based task execution) and `VtTaskQueueDb` (Dexie-persisted task queue). Used by shape-plugin and route-plugin build pipelines.

## Dependencies

`@hierarchidb/build-api`, `@hierarchidb/chunk-store`, `@hierarchidb/core-types`, `@hierarchidb/gis-sdk`, `@hierarchidb/plugin-service-api`, `@hierarchidb/shape-api`, `@hierarchidb/util`, `@hierarchidb/shape-store`

## Related Packages

- [`@hierarchidb/vectortile-store`](../vectortile-store/) — Vector tile store
- [`@hierarchidb/build`](../build/) — Build system foundation
