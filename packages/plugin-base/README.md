# @hierarchidb/plugin-base

Headless orchestration utilities for HierarchiDB plugin dialogs. This package hosts the step registry, working-copy bridge, and related hooks that power plugin dialog extensions.

## Contents
- Step registries (`PluginStepRegistry`, `HostProfileRegistry`)
- Working copy & worker-bridge hooks
- Dialog state helpers (URL sync, presentation cache)

## Build
```
pnpm --filter @hierarchidb/plugin-base build
```
