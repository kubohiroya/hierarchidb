# @hierarchidb/auth

最終更新: 2026-04-05

HierarchiDB の認証基盤パッケージ。`fetchWithAuth`（認証付き fetch ラッパー、401 自動復帰）、トークン管理、認証状態管理を提供する。

## 依存関係

`@hierarchidb/auth-api`, `@hierarchidb/util`

## 関連パッケージ

- [`@hierarchidb/auth-api`](../auth-api/) — 認証 API 型定義
- [`@hierarchidb/download`](../download/) — ダウンロードサービス（auth を使用）
