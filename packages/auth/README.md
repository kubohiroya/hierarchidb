# @hierarchidb/auth

Last updated: 2026-04-05

Authentication foundation package for HierarchiDB. Provides `fetchWithAuth` (authenticated fetch wrapper with 401 auto-recovery), token management, and authentication state management.

## Dependencies

`@hierarchidb/auth-api`, `@hierarchidb/util`

## Related Packages

- [`@hierarchidb/auth-api`](../auth-api/) — Authentication API type definitions
- [`@hierarchidb/download`](../download/) — Download service (uses auth)
