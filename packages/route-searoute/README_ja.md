# @hierarchidb/route-searoute

最終更新: 2026-04-05

HierarchiDB の海上ルート計算パッケージ。searoute-js を利用して港湾間の海上ルート（GeoJSON LineString）を計算する。

## 依存関係

`@hierarchidb/download`

## 関連パッケージ

- [`@hierarchidb/route-engine`](../route-engine/) — ルート生成エンジン（searoute メソッドの実装先）
- [`@hierarchidb/route-api`](../route-api/) — Route API 型定義
