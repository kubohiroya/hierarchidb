# 要望: 入力送信キーのカスタマイズ（Meta/Ctrl+Enterで送信、Enterで改行）

## 背景
- 日本語入力で変換確定に Enter を多用するため、誤送信が発生しやすい。
- 長文作成時に「変換→確定→送信」が混在し、作業効率が下がる。

## 要望
- 送信キーを設定で切替可能にしてほしい。
  - モード例:
    - Enter=改行、Meta(⌘)+Enter=送信
    - Enter=改行、Ctrl+Enter=送信
    - 現行: Enter=送信（デフォルト互換）
- コンポーズモードの追加:
  - ON中は Enter=常に改行、修飾キーのみ送信。
- 入力欄付近に現在のショートカット表示（例: “送信: ⌘Enter / 改行: Enter”）。
- 設定の保持方法（設定ファイル/環境変数/アプリ設定）を提供。

## 受け入れ基準
- 設定で送信キーを切替できる。
- IME 利用時の誤送信が実質ゼロになる。
- ヘルプ/ドキュメントへ反映される。

## 互換性/配慮
- OS 別のキーバインド衝突（macOS/Linux/Windows）に配慮。
- 既定値は現行の挙動を維持し、互換性を担保。
