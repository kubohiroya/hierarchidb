# @hierarchidb/location-store

最終更新: 2026-04-05

HierarchiDB の Location データストアパッケージ。Dexie（IndexedDB）ベースの `LocationDB` を提供し、位置フィーチャ（空港・港湾・鉄道駅等）の永続化・Morton キー空間インデックスを管理する。location-plugin の Worker 層が使用する。

## 依存関係

`@hierarchidb/core-types`, `@hierarchidb/location-api`, `@hierarchidb/shape-store`, `@hierarchidb/util`, `@hierarchidb/vectortile-store`

## 関連パッケージ

- [`@hierarchidb/location-api`](../location-api/) — Location API 型定義
- [`@hierarchidb/shape-store`](../shape-store/) — Shape データストア（Shape 連携）
