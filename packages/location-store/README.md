# @hierarchidb/location-store

Last updated: 2026-04-05

Location data store package for HierarchiDB. Provides the Dexie (IndexedDB)-based `LocationDB` for persisting location features (airports, ports, railway stations, etc.) with Morton key spatial indexing. Used by the location-plugin Worker layer.

## Dependencies

`@hierarchidb/core-types`, `@hierarchidb/location-api`, `@hierarchidb/shape-store`, `@hierarchidb/util`, `@hierarchidb/vectortile-store`

## Related Packages

- [`@hierarchidb/location-api`](../location-api/) — Location API type definitions
- [`@hierarchidb/shape-store`](../shape-store/) — Shape data store (Shape integration)
