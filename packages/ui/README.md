# HierarchiDB UI packages

React/MUI-based UI libraries for HierarchiDB. Key areas:

- Dialogs & host integration: `ui-dialog`, `plugin-ui-host`, `plugin-ui-sdk`, `plugin-base`, `plugin-shell`.
- Map: `ui-map` (MapLibre + deck overlay), works with `map-source`/`map-adapter`.
- Auth: `ui-auth`, `ui-usermenu`, `ui-i18n`.
- TreeConsole: `ui-treeconsole-*` (breadcrumb/toolbar/treetable) and `ui/plugin-shell` bundle entry points.
- Utilities/components: `ui/floating-window`, `ui/lru-splitview`, `ui/accordion-config`, `ui/file`, `ui/datasource`, `ui/search-result-window`, `ui/license`, `ui/country-select`.
- Worker bridge: `ui/worker-client`.

See each package’s README for structure, exports, and consumers.
