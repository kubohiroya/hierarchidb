# @hierarchidb/style-api

最終更新: 2026-04-05

HierarchiDB の Style API 型定義パッケージ。StyleRecord、StyleDescriptor、StyleType、StyleValueType 等の型定義を提供する。styler-plugin と styler-store の間の契約を定義する。

## 依存関係

- [`@hierarchidb/core-types`](../core-types/) — 共有型定義
