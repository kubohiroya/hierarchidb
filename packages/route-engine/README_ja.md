# @hierarchidb/route-engine

最終更新: 2026-04-05

HierarchiDB のルート生成エンジンパッケージ。始点・終点座標からルートジオメトリを生成する `RouteGenerator` を提供する。direct / great_circle / OSRM / searoute 等の生成メソッドをサポートする。

## 依存関係

`@hierarchidb/route-store`, `@hierarchidb/util`

## 関連パッケージ

- [`@hierarchidb/route-api`](../route-api/) — Route API 型定義
- [`@hierarchidb/route-store`](../route-store/) — Route データストア
- [`@hierarchidb/route-searoute`](../route-searoute/) — 海上ルート計算
