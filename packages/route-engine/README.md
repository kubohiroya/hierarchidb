# @hierarchidb/route-engine

Last updated: 2026-04-05

Route generation engine for HierarchiDB. Provides `RouteGenerator` for generating route geometries from origin/destination coordinates. Supports direct, great_circle, OSRM, searoute, and other generation methods.

## Dependencies

`@hierarchidb/route-store`, `@hierarchidb/util`

## Related Packages

- [`@hierarchidb/route-api`](../route-api/) — Route API type definitions
- [`@hierarchidb/route-store`](../route-store/) — Route data store
- [`@hierarchidb/route-searoute`](../route-searoute/) — Maritime route calculation
