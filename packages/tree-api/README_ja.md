# @hierarchidb/tree-api

最終更新: 2026-04-05

HierarchiDB のツリー API 型定義パッケージ。`TreeNode`、`TreeNodeUpdaterPayload`、`TreeQueryAPI` 等のツリー構造操作に必要な型を提供する。全プラグインが TreeNode の CRUD に使用する。

## 依存関係

`@hierarchidb/core-types`

## 関連パッケージ

- [`@hierarchidb/core-types`](../core-types/) — NodeId、NodeType 等の ID 型
- [`@hierarchidb/runtime-worker`](../runtime-worker/) — CoreDB（TreeNode の実装）
