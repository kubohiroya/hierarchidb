# @hierarchidb/tree-api

Last updated: 2026-04-05

Tree API type definitions for HierarchiDB. Provides `TreeNode`, `TreeNodeUpdaterPayload`, `TreeQueryAPI`, and other types needed for tree structure operations. Used by all plugins for TreeNode CRUD.

## Dependencies

`@hierarchidb/core-types`

## Related Packages

- [`@hierarchidb/core-types`](../core-types/) — ID types (NodeId, NodeType, etc.)
- [`@hierarchidb/runtime-worker`](../runtime-worker/) — CoreDB (TreeNode implementation)
