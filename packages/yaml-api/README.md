# @hierarchidb/yaml-api

Last updated: 2026-04-05

YAML API type definitions for HierarchiDB. Provides `YamlFileNodeData` (name, schemaId, content), `YAML_NODE_TYPE`, etc. Defines the contract between yaml-plugin and yaml-store.
