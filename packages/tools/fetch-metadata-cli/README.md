# @hierarchidb/tools-fetch-metadata

Command-line helper that wraps `@hierarchidb/runtime-shared-fetch-metadata` to prefetch and persist metadata files.

## Usage

```
pnpm --filter @hierarchidb/tools-fetch-metadata build
pnpm --filter @hierarchidb/tools-fetch-metadata fetch gadm ./output gadm.json
```

## Development

- `pnpm --filter @hierarchidb/tools-fetch-metadata dev` — watch build
- `pnpm --filter @hierarchidb/tools-fetch-metadata lint`
- `pnpm --filter @hierarchidb/tools-fetch-metadata typecheck`
