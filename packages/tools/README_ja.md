# @hierarchidb/tools

最終更新: 2026-04-05

HierarchiDB のビルド・コード生成ツール群。ライセンス解析、ビルドスクリプト、コードモッド、ISO 3166-2 コード生成、プラグインマニフェスト読込、パス変換、スキーマ定義等のツールを含む。

## 配下ツール一覧

| パッケージ | 説明 |
| --- | --- |
| [analyze-licenses](./analyze-licenses/) | 依存パッケージのライセンス解析 |
| [build-scripts](./build-scripts/) | ビルドスクリプトユーティリティ |
| [codemods](./codemods/) | コードモッド（自動コード変換） |
| [gen-iso3166-2](./gen-iso3166-2/) | ISO 3166-2 コード生成・国コード正規化 |
| [load-plugin-manifest](./load-plugin-manifest/) | プラグインマニフェスト読込ツール |
| [rel2abs](./rel2abs/) | 相対パス→絶対パス変換 |
| [schemas](./schemas/) | スキーマ定義ツール |
