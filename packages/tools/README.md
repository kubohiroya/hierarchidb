# @hierarchidb/tools

Last updated: 2026-04-05

Build and code generation tools for HierarchiDB. Includes license analysis, build scripts, codemods, ISO 3166-2 code generation, plugin manifest loading, path conversion, and schema definition tools.

## Tools

| Package | Description |
| --- | --- |
| [analyze-licenses](./analyze-licenses/) | Dependency license analysis |
| [build-scripts](./build-scripts/) | Build script utilities |
| [codemods](./codemods/) | Codemods (automated code transformations) |
| [gen-iso3166-2](./gen-iso3166-2/) | ISO 3166-2 code generation and country code normalization |
| [load-plugin-manifest](./load-plugin-manifest/) | Plugin manifest loading tool |
| [rel2abs](./rel2abs/) | Relative-to-absolute path conversion |
| [schemas](./schemas/) | Schema definition tools |
