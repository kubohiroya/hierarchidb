# @hierarchidb/yaml-store

Last updated: 2026-04-05

YAML data store package for HierarchiDB. Provides the Dexie-based `YamlDB` for persisting YAML file nodes. The yaml-plugin Worker layer retrieves the singleton via `getYamlDB()`.

## Dependencies

`@hierarchidb/core-types`, `@hierarchidb/util`, `@hierarchidb/yaml-api`

## Related Packages

- [`@hierarchidb/yaml-api`](../yaml-api/) — YAML API type definitions
- [`@hierarchidb/core-types`](../core-types/) — Shared type definitions
