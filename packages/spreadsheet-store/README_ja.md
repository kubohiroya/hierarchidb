# @hierarchidb/spreadsheet-store

最終更新: 2026-04-05

HierarchiDB の Spreadsheet データストアパッケージ。SpreadsheetEntity 型定義と、tabular-store を基盤とした表データメタデータ管理を提供する。spreadsheet-plugin が使用する。

## 依存関係

`@hierarchidb/core-types`, `@hierarchidb/tabular-store`, `@hierarchidb/ui-tabular`

## 関連パッケージ

- [`@hierarchidb/tabular-store`](../tabular-store/) — 表データストア基盤
- [`@hierarchidb/styler-store`](../styler-store/) — Styler データストア（spreadsheet-store に依存）
