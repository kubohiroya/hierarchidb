# @hierarchidb/spreadsheet-store

Last updated: 2026-04-05

Spreadsheet data store package for HierarchiDB. Provides SpreadsheetEntity type definitions and tabular data metadata management built on tabular-store. Used by spreadsheet-plugin.

## Dependencies

`@hierarchidb/core-types`, `@hierarchidb/tabular-store`, `@hierarchidb/ui-tabular`

## Related Packages

- [`@hierarchidb/tabular-store`](../tabular-store/) — Tabular data store foundation
- [`@hierarchidb/styler-store`](../styler-store/) — Styler data store (depends on spreadsheet-store)
