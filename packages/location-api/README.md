# @hierarchidb/location-api

Last updated: 2026-04-05

Location API type definitions for HierarchiDB. Provides type definitions for LocationEntity, LocationFeature, LocationGroupItemData, LocationBuildConfig, etc. Defines the contract between location-plugin and location-store.

## Dependencies

`@hierarchidb/core-types`, `@hierarchidb/gen-iso3166-2`, `@hierarchidb/util`

## Related Packages

- [`@hierarchidb/location-store`](../location-store/) — Location data store (implementation)
- [`@hierarchidb/core-types`](../core-types/) — Shared type definitions
