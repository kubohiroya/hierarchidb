# @hierarchidb/location-api

最終更新: 2026-04-05

HierarchiDB の Location API 型定義パッケージ。LocationEntity、LocationFeature、LocationGroupItemData、LocationBuildConfig 等の型定義を提供する。location-plugin と location-store の間の契約を定義する。

## 依存関係

`@hierarchidb/core-types`, `@hierarchidb/gen-iso3166-2`, `@hierarchidb/util`

## 関連パッケージ

- [`@hierarchidb/location-store`](../location-store/) — Location データストア（実装）
- [`@hierarchidb/core-types`](../core-types/) — 共有型定義
