# @hierarchidb/route-store

最終更新: 2026-04-05

HierarchiDB の Route データストアパッケージ。Dexie（IndexedDB）ベースの `RouteDB` を提供し、ルートフィーチャ・ベクトルタイルの永続化を管理する。route-plugin の Worker 層が使用する。

## 依存関係

`@hierarchidb/core-types`, `@hierarchidb/route-api`, `@hierarchidb/util`, `@hierarchidb/vectortile-store`

## 関連パッケージ

- [`@hierarchidb/route-api`](../route-api/) — Route API 型定義
- [`@hierarchidb/route-engine`](../route-engine/) — ルート生成エンジン
