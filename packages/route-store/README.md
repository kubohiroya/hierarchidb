# @hierarchidb/route-store

Last updated: 2026-04-05

Route data store package for HierarchiDB. Provides the Dexie (IndexedDB)-based `RouteDB` for persisting route features and vector tiles. Used by the route-plugin Worker layer.

## Dependencies

`@hierarchidb/core-types`, `@hierarchidb/route-api`, `@hierarchidb/util`, `@hierarchidb/vectortile-store`

## Related Packages

- [`@hierarchidb/route-api`](../route-api/) — Route API type definitions
- [`@hierarchidb/route-engine`](../route-engine/) — Route generation engine
