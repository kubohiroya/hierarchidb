# plugins-spreadsheet-plugin テストケース洗い出し

## 開発言語・フレームワーク

- **プログラミング言語**: TypeScript
  - **言語選択の理由**: HierarchiDBプロジェクトの標準言語、型安全性の確保、branded typeサポート
  - **テストに適した機能**: 型チェック、インターフェース実装確認、コンパイル時エラー検出
- **テストフレームワーク**: Vitest
  - **フレームワーク選択の理由**: 既存プロジェクトで使用、高速実行、ESModules対応、TypeScript統合
  - **テスト実行環境**: Node.js環境、fake-indexeddb使用でIndexedDB模擬
- 🟢 既存のVitest設定とfake-indexeddbテストパターンに完全一致

## サポートファイル形式（最終版）

- **CSV形式** (`.csv`) - カンマ区切り
- **TSV形式** (`.tsv`) - タブ区切り  
- **テキストファイル** (`.txt`) - CSV形式として処理
- **ZIP圧縮ファイル** (`.zip`) - CSV/TSV/XLSX/XLSファイルを含む圧縮ファイル ✨**新規追加**
- **Excel形式** (`.xlsx`) - Excel 2007以降形式 ✨**新規追加**
- **Excel形式** (`.xls`) - Excel 2003以前形式 ✨**新規追加**

### 外部ライブラリ依存
- **SheetJS** (`xlsx`) - Excel/CSV処理用ライブラリ、ブラウザ環境対応
- **JSZip** または同等 - ZIP圧縮ファイル処理用ライブラリ
